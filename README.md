### 📂 Organização do Código | Code Structure

🇧🇷 **Principais diretórios:**
* `lib/`: Contém as telas (UI) e a lógica de navegação.
* `custom_code/`: Funções, ações e widgets personalizados criados para estender as capacidades do FlutterFlow.
* `firebase/`: Configurações de segurança e regras do banco de dados (Firestore).

🇺🇸 **Main directories:**
* `lib/`: Screens (UI) and navigation logic.
* `custom_code/`: Functions, actions, and custom widgets built to extend FlutterFlow capabilities.
* `firebase/`: Security configurations and database rules (Firestore).
